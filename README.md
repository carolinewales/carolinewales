# Caroline Wales — Portfolio

Layout, typography, and spacing closely matched to a reference site
(Playfair Display serif headings, Inter body text, timeline-style
experience, dark closing section) rebuilt entirely in navy/teal with your
content. All CSS and JS are inlined directly into index.html.

## Before you publish — 1 thing left to finish

**Add your video** — film it, upload as **Unlisted** on YouTube (or use
Loom), then in `index.html` find the `<!-- REPLACE THIS PLACEHOLDER -->`
comment in the Video section, uncomment the `<iframe>` line and add your
video ID, and delete the `.video-placeholder` div below it.

## Publishing with GitHub Pages

1. Push everything in this folder to your repo, with `index.html` at the top level.
2. Repo **Settings → Pages → Source → Deploy from a branch → main / (root)** → Save.
3. GitHub gives you a live URL in a minute or two — that's what you submit on Canvas.
4. Test on your phone before submitting.

## Submission checklist
- [ ] Canvas comment states track: **"Targeting Track"**
- [ ] Site is public — no password, no login required
- [ ] Tested on both a laptop browser and a phone
- [ ] Video embedded and playable
